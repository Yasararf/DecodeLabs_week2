# Student Grade Calculator

## 📌 Project Description

The **Student Grade Calculator** is a Java-based application that calculates a student's academic performance based on marks obtained in multiple subjects.

The program accepts marks from the user, calculates the **total marks** and **average percentage**, and assigns a **grade** based on the calculated percentage.

## 🚀 Features

* Accepts the number of subjects from the user
* Takes marks for each subject
* Calculates the total marks
* Calculates the average percentage
* Assigns a grade based on the average percentage
* Displays the final result clearly

## 🛠️ Technologies Used

* Java
* Scanner Class
* Loops
* Conditional Statements
* Arithmetic Operations

## 📊 Grade Criteria

| Percentage   | Grade |
| ------------ | ----- |
| 90 and above | A+    |
| 80 - 89      | A     |
| 70 - 79      | B     |
| 60 - 69      | C     |
| 50 - 59      | D     |
| Below 50     | F     |

## 💻 How the Program Works

1. The user enters the number of subjects.
2. The program asks the user to enter marks for each subject.
3. The marks are added to calculate the total.
4. The average percentage is calculated.
5. Based on the average percentage, a grade is assigned.
6. The final result is displayed.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in any Java IDE such as VS Code, IntelliJ IDEA, or Eclipse.
3. Compile the program:

```bash
javac StudentGradeCalculator.java
```

4. Run the program:

```bash
java StudentGradeCalculator
```
