Student Grade Calculator
📌 Project Description
The Student Grade Calculator is a Java-based application that calculates a student's academic performance based on marks obtained in multiple subjects.

The program accepts marks from the user, calculates the total marks and average percentage, and assigns a grade based on the calculated percentage.

🚀 Features
Accepts the number of subjects from the user
Takes marks for each subject
Calculates the total marks
Calculates the average percentage
Assigns a grade based on the average percentage
Displays the final result clearly
🛠️ Technologies Used
Java
Scanner Class
Loops
Conditional Statements
Arithmetic Operations
📊 Grade Criteria
Percentage	Grade
90 and above	A+
80 - 89	A
70 - 79	B
60 - 69	C
50 - 59	D
Below 50	F
💻 How the Program Works
The user enters the number of subjects.
The program asks the user to enter marks for each subject.
The marks are added to calculate the total.
The average percentage is calculated.
Based on the average percentage, a grade is assigned.
The final result is displayed.
▶️ How to Run
Clone or download this repository.
Open the project in any Java IDE such as VS Code, IntelliJ IDEA, or Eclipse.
Compile the program:
javac StudentGradeCalculator.java
Run the program:
java StudentGradeCalculator
